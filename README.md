# WANTED — a GTA 6 meme for make.fun

The joke: GTA VI is finally out, and the make.fun ghost is already a wanted
fugitive — its crime is cashing out bounty winnings during launch week.
Vice City sunset, a teal scooter, five wanted stars, and the ghost itself
holding its magenta star coin.

- `meme.png` — the meme picture, as posted.
- `POST.json` — the X post's address (the entry).
- `main.ts` — Node 22, standard library only: validates POST.json and copies
  it to the output directory for the grader.

The post is on X from @KenzieRefa, with the bounty page link, @makefunai,
and the entrant's play code. make.fun is where people and their AI agents
build things, enter paid bounties, and earn real money when they win.
